# MOO3DSTUDIO

**الإصدار 0.0.0.1 · Windows x64**

برنامج عربي لتسعير وإدارة شغل الطباعة ثلاثية الأبعاد. احسب تكلفة الأوردر وسعر البيع، وسجّل استهلاك الخامات والمبيعات والمشتريات من نفس البرنامج. البيانات محفوظة محليًا على جهازك.

## المميزات

- احسب السعر بناءً على وزن كل خامة، وقت الطباعة، تشغيل الطابعة، الكهرباء، الشغل اليدوي، والهالك والإضافات.
- أضف أكتر من لون للأوردر. لما تشيل لون قبل الحفظ، السعر بيتحدّث وجرامات باقي الألوان بتفضل زي ما هي.
- تابع رصيد الخامات وحركات المخزون. الخامات المستخدمة بتتخصم عند تسجيل الأوردر.
- سجّل المشتريات والأصول، وراجع المبيعات والأرباح، واطبع فاتورة للعميل.
- صدّر نسخة احتياطية واسترجعها من الإعدادات.

## تنزيل البرنامج

1. افتح [GitHub Actions](https://github.com/Ms-Studio-3d/MOO3DSTUDIO/actions) واختر أحدث تشغيل ناجح لـ **Build Windows Installer**.
2. من **Artifacts** حمّل **MOO3DSTUDIO-Windows-Installer**.
3. فك الضغط وشغّل **MOO3DSTUDIO-Setup-0.0.0.1.exe**.

## أول تشغيل

أضف الخامات بألوانها ووزن البكرة وسعرها والجرامات المتاحة. راجع تكلفة تشغيل الطابعة والكهرباء والصيانة والإهلاك حسب أرقام شغلك، وجرّب تسعير أوردر معروف قبل أول بيع.

قاعدة بيانات البرنامج في `%APPDATA%\MOO3DSTUDIO`. النسخ الاحتياطية في `Documents\MOO3DSTUDIO\Backups`.

## بناء نسخة من المصدر

في GitHub افتح **Actions → Build Windows Installer → Run workflow**. للبناء محليًا على Windows، استخدم Node.js 22 وشغّل `BUILD-WINDOWS.cmd`. هتلاقي المثبّت في مجلد `dist` بعد نجاح البناء.

سير البناء يشغّل اختبارات التسعير والمخزون والثبات، ويتحقق من تشغيل SQLite داخل Electron قبل إنشاء المثبّت. راجع [دليل البداية](START-HERE.html) لتجربة أول أوردر والنسخ الاحتياطية.
