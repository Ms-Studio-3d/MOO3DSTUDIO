# MOO3D Farm

الإصدار **0.0.4** من **MOO3DSTUDIO**.

برنامج عربي لـWindows لتسعير الطباعة ثلاثية الأبعاد وإدارة الأوردرات والخامات.

يعرض حالة النسخ الاحتياطي ووقت آخر نسخة تلقائية ناجحة، مع تنبيه عند الفشل وزر لحفظ نسخة جديدة من الإعدادات.

ينتظر عند الإغلاق العمليات المقبولة والنسخة الجارية، ثم يحفظ نسخة جديدة تشمل آخر التعديلات. عند تعذر اكتمال نسخة الإغلاق يحتفظ بتنبيه الفشل للفتح التالي.

[تحميل نسخة Windows](https://github.com/Ms-Studio-3d/MOO3DSTUDIO/actions) — افتح أحدث تشغيل ناجح وحمّل المثبّت من **Artifacts**.
